# 100_days_of_code <br>
This repository contains my work for the 100 Days of Code in C Programming challenge assigned as part of my college curriculum at UPES. <br>

The challenge is focused on developing consistency in programming and strengthening my understanding of the C programming language through regular coding practice and problem-solving. <br>

Throughout the challenge, I will be working through different programming exercises, gradually building my fundamentals in C and improving my logical thinking and problem-solving skills. <br>

🎯 Objectives <br>
Build a strong foundation in C programming <br>
Practice programming consistently for 100 days <br>
Improve logical thinking and problem-solving skills <br>
Understand programming concepts through hands-on practice <br>
Maintain a record of my progress throughout the challenge <br>
